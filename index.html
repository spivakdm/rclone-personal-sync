rclone — Personal document sync

A personal Google OAuth application operated by the account owner to synchronize documents between the owner’s Linux computer and Google Drive using the open-source rclone software.

Purpose and access

This configuration is intended for the owner's own Google account. It requests Google Drive access so rclone can list, read, upload, update and delete files as needed for two-way synchronization of a selected Documents folder. The requested permission can cover the whole Drive; the selected folder is a configuration choice, not an OAuth permission boundary.

Transfers take place between the owner's computer and Google Drive. This website provides application information only and does not receive document contents or OAuth tokens.

Privacy and control

Read the privacy policy for data handling and access revocation details.

Support contact: use the user support email displayed on the Google authorization screen.

This is a personal configuration of rclone, not the official rclone project or a Google product.
